# ChatSphere

A responsive React + Vite chat frontend with login, registration, contact search, conversation switching, and local demo messaging.

## Run it

```bash
npm install
npm run dev
```

The app connects to `https://chatsphere-1-8q32.onrender.com` for `/api/auth/login` and `/api/auth/signup` when your backend is running. If the API is unavailable, it automatically opens in demo mode so the UI can still be explored.
